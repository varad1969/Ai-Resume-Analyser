# AI Resume Analyser

An AI-powered web application that analyzes resumes and provides insights based on the candidate's skills, experience, education, and job requirements.

## 🚀 Features

- Resume upload and analysis
- AI-powered resume evaluation
- Skill and experience analysis
- Job description matching
- Resume feedback
- Candidate insights
- User-friendly web interface
- Secure backend APIs

## 🛠️ Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- REST APIs
- Maven

### Frontend
- React
- JavaScript
- Vite
- HTML
- CSS

### Database
- MySQL
